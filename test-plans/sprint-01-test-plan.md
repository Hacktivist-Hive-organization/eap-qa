# Sprint-01 Test Plan — EAP

## 1. Scope
Sprint 1 focuses on:
- repo structure readiness (QA)
- CI pipelines (GitHub Actions) operational
- test reporting and artifacts are produced

## 2. Deliverables
- Testing docs merged:
  - Test Strategy
  - ADR-001 (E2E Framework)
  - ADR-002 (Test Data Strategy)
  - Regression Test Plan

## 3. Entry criteria
- repos created and reachable
- GitHub Actions runners enabled and secrets configured (as needed)

## 4. Exit criteria
- CI is green on PR for scaffolding repos
- test job produces artifacts (report folder exists even if no tests)

## 5. Risks & mitigations
- Environment instability
