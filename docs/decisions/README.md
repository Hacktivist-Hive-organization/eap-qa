# EAP – Testing Documentation

This directory contains quality assurance (QA) architectural designs and test strategy documentation for the  **Enterprise Application Project (EAP)**.

These documents define **how** the system is tested, **what** is tested at each stage, and **when** different test suites are executed in the CI/CD pipeline.

The documentation is designed to support:
- consistent testing practices across the team
- automation-first development
- auditability and traceability
- scalable CI/CD workflows
